# Templates Overview

Documentation templates used when writing the `.md` files in this repository. Each subfolder holds one `Template.md`; copy it, fill in the placeholders and delete the instruction block at the top.

---

## Templates

| Template | For |
| --- | --- |
| [Overview/Template.md](Overview/Template.md) | `Overview.md` — the index of a folder |
| [Shell/Template.md](Shell/Template.md) | Documentation for a `.sh` script |
| [PowerShell/Template.md](PowerShell/Template.md) | Documentation for a `.ps1` script |
| [Python/Template.md](Python/Template.md) | Documentation for a `.py` script |

---

## Notes

- The templates contain no scripts, so the subfolders have no `Overview.md` of their own.
